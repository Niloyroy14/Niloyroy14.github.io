# Niloy Roy — Portfolio Website

A static personal portfolio website built with pure HTML, CSS, and JavaScript.

## Folder Structure

```
niloy-portfolio/
├── index.html          ← Main HTML (all sections)
├── css/
│   └── style.css       ← All styles + dark/light theme variables
├── js/
│   └── main.js         ← Cursor, scroll reveal, tabs, slider, theme toggle
├── images/
│   ├── myimage.png     ← YOUR PHOTO — replace this file (keep same name)
│   ├── nexgo-g25.png   ← NEXGO G25 POS Terminal
│   ├── sunmi-p2-pro.jpg← Sunmi P2 Pro Android device
│   ├── sunmi-d3-mini.png← Sunmi D3 Mini Android device
│   ├── castles-vega.webp← Castles Vega 3000 POS Terminal
│   ├── tom-desktop.png ← TOM Desktop project card image
│   ├── transport-web.png← Transport Monitor project card image
│   ├── clearing-api.png← Clearing House API project card image
│   ├── rapidpass-web.png← Rapid Pass website project card image
│   ├── ehazira-web.png ← e-Hazira platform project card image
│   ├── foodhub-react.png← FoodHub panel project card image
│   ├── qt-desktop.png  ← QT Desktop apps project card image
│   ├── ml-classify.png ← ML Classification project card image
│   └── ml-sentiment.png← ML Sentiment project card image
└── README.md
```

## How to Use

1. Open `index.html` in any browser — no build tools needed.
2. **Replace your photo:** Drop your photo into `images/` named exactly `myimage.png`.
3. **Dark / Light toggle:** Click the 🌙/☀️ button in the top-right navbar. Preference is saved to localStorage.
4. **Project tab filter:** Click tabs (All, Embedded, Linux Devices, Android, Web, ML) to filter.
